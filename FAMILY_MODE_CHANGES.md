# Family Mode UI changes

- Family Mode navigation: Chats + Calls only.
- Voice messages: recorded/sent from the chat composer microphone control.
- Tic-Tac-Toe: grid button next to the microphone in the chat composer.
- Direct chat: tapping the game button opens Tic-Tac-Toe and automatically invites the person in that chat.
- Group chat: tapping the game button opens Tic-Tac-Toe without auto-selecting a player.
- Admin Mode navigation remains unchanged.
- Admin email: quixoratech@gmail.com; app-side and Firestore-rule checks both enforce the allowlist.

Build and run the project on a real Android device to validate UI layout, navigation, invitations, and runtime permissions.
